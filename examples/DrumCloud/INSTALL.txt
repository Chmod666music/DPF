cat << 'EOF' > INSTALL.txt
Installation Instructions for DrumCloud

1. Extract the ZIP archive.
2. Open your terminal and navigate to the extracted folder.
3. Run the installation script by typing:
   ./install.sh
4. Rescan plugins in your DAW.

Manual Installation:
If you prefer not to use the script, you can manually copy the plugin file (.clap, .vst3, .lv2, or .so) to your standard Linux plugin folders (e.g., ~/.clap, ~/.vst3, ~/.lv2, ~/.vst).
EOF
